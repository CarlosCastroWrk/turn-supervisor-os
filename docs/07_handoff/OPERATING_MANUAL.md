# Operating Manual

## Daily Loop

1. Check current state.
2. Pull the next task from the build queue.
3. Confirm assumptions and risks.
4. Make the smallest safe change.
5. Run relevant verification.
6. Update work log, build queue, and handoff notes.

## Decision Discipline

Any decision that affects architecture, security, data, deployment, or product scope
should be recorded in `ops/decisions/`.
