# Official PDS Links Policy

## Approved Candidate Destinations

| Label | URL |
| --- | --- |
| Change Order Approval | `https://pds.jotform.com/251384128606962` |
| Backup Safety Submission Box | `https://pds.jotform.com/231955109224959` |

## Placement

- `More → Work → Official PDS Forms`
- Optional compact `Forms` shortcut from Today

## Required Behavior

- Open the destination externally in the device browser.
- Clearly label it as an official external PDS form.
- Require an explicit user tap.
- Keep URLs in one replaceable configuration module rather than scattering them through views.
- Preserve the destination URL visibly enough for Los to understand where he is going.

## Prohibited Behavior

- No embedding inside Turn OS.
- No prefill or automatic navigation.
- No submission, signature capture, completion tracking, or form-content storage.
- No W-9, paycard, payroll, or QR-image storage.
- No claim that Turn OS owns, validates, or receives the official submission.

## Privacy Boundary

Turn OS may remember that Los opened a link only if that event contains no completed-form contents or sensitive identifiers. The candidate should default to no retained external-form activity unless a clear personal utility and permitted retention rule are documented.
